材料科学基础 · 计算题整理（含全部题型）

覆盖讲义与习题集中的全部计算/综合题，共 6 类题型 + 铁碳相图综合题模板。
用法：先看「必备公式」，再逐题手写一遍（抄公式 → 代数据 → 写答案），考场上写公式就有分。

二、题型一：堆积与晶胞体积计算

题目：假设刚性球模型的球直径不变，晶体由面心立方（fcc）变成体心立方（bcc）时，计算体积膨胀率。

解（按每个原子的体积算，因为原子数不变）：

  1. fcc：a = 2√2·r，单胞体积 16√2·r³，每胞 4 原子 → 每原子 4√2·r³；
  2. bcc：a = 4r/√3，单胞体积 64/(3√3)·r³，每胞 2 原子 → 每原子 32/(3√3)·r³；
  3. 膨胀率 = [32/(3√3) − 4√2] ÷ (4√2) × 100% = ≈ 8.9%（约膨胀 8.9%）。

易错：不能用"单胞体积"直接比，fcc 和 bcc 每胞原子数不同，必须换算成每原子体积。

三、题型二：渗碳时间（菲克第二定律误差函数解）

题目：950℃ 对纯铁渗碳，要求 0.1 mm 深处含碳 0.9%，表面碳含量保持 1.20%，D(γ-Fe) = 10⁻¹⁰ m²/s，求最少渗碳时间。

解：

  1. 列已知量：x = 0.1 mm = 10⁻⁴ m；Ws = 1.20%；W = 0.9%；W0 = 0；D = 10⁻¹⁰ m²/s；
  2. 套公式：(1.20 − 0.9)/(1.20 − 0) = 0.25 = erf( x/(2√(Dt)) )；
  3. 查误差函数表：erf⁻¹(0.25) ≈ 0.225，即 x/(2√(Dt)) = 0.225；
  4. √(Dt) = 10⁻⁴/(2 × 0.225) ≈ 2.22 × 10⁻⁴ m；
  5. t = (2.22 × 10⁻⁴)² ÷ 10⁻¹⁰ ≈ 494 s ≈ 8 min。

注意：资料里出现"327 s"和"约 7.9 min"两种写法（两者本身不一致）。按公式完整计算约为 8 min 量级（≈490 s），与习题答案"约 7.9 min"吻合。考场上务必把公式、代入、查表过程写全，数值写量级即可。

四、题型三：临界晶核半径

题目：一个大气压下液态铝凝固，过冷度 ΔT = 10℃。已知 Tm = 993 K，熔化热 Lm = 1.836×10⁹ J/m³，固液界面能 σ = 93 mJ/m²，求临界晶核尺寸。

解：

  1. 单位换算：σ = 93 mJ/m² = 0.093 J/m²；ΔT = 10 K；
  2. 套公式：r* = 2σ·Tm/(Lm·ΔT) = 2 × 0.093 × 993 / (1.836×10⁹ × 10)；
  3. 计算：r* ≈ 1.0 × 10⁻⁸ m = 10 nm。

五、题型四：杠杆定律（Pb-Sn 共晶合金）★

相图端点（183℃）：α 端 = 19%Sn，共晶点 = 61.9%Sn，β 端 = 97.5%Sn。

解题套路：

  • 组织组成物（问"先共晶 α / 共晶(α+β)"）：以共晶点 61.9 为界，α初 = (61.9 − C0)/(61.9 − 19)；
  • 相组成物（问"α 相 / β 相总量"）：以两端点 19 与 97.5 为界，α = (97.5 − C0)/(97.5 − 19)。

例 1：w(Sn) = 45% 合金，183℃

组成物 计算 结果
先共晶 α初 (61.9−45)/(61.9−19) 38.3%
共晶 (α+β) 1 − 38.3% 61.7%
α 相总量 (97.5−45)/(97.5−19) 67%
β 相总量 1 − 67% 33%

例 2：w(Sn) = 50% 合金

室温平衡组织：α初 + (α+β)共 + βⅡ（过共晶点成分，共晶后 β 还会沿固溶线析出 βⅡ）。

组成物 计算 结果
先共晶 α初 (61.9−50)/(61.9−19) ≈28%
共晶 (α+β)共 1 − 28% 72%
α 相总量 (97.5−50)/(97.5−19) 60.5%
β 相总量 1 − 60.5% 39.5%

六、题型五：铁碳合金相组成物反推含碳量 ★

题目：某铁碳合金室温相组成物为铁素体 + 渗碳体，铁素体占 82%，求含碳量及组织组成物相对量。

解：

  1. 设含碳量为 x%：QF = (6.69 − x)/(6.69 − 0.0008) = 82%；
  2. 解得 x ≈ 1.2% → 属过共析钢（0.77~2.11%）；
  3. 室温组织组成物为 P + Fe₃CⅡ：
    - QP = (6.69 − 1.2)/(6.69 − 0.77) = 92.7%；
    - QFe₃CⅡ = (1.2 − 0.77)/(6.69 − 0.77) = 7.3%。

七、题型六：三元合金成分计算

题目：三元合金 K 在 t₁ 分解为纯 B 组元和液相 L，WB/WL = 2，液相中 B 含量 40%；已知合金中 A 与 C 的质量比为 3，求 K 的成分。

解：

  1. 在 B-K-L 连线上用杠杆定律：WB/WL = (XB − 40)/(100 − XB) = 2；
  2. XB − 40 = 200 − 2XB → 3XB = 240 → XB = 80%；
  3. XA + XC = 100% − 80% = 20%，且 XA/XC = 3；
  4. 解得 XA = 15%，XC = 5%。

八、附 A：Fe-Fe₃C 画图/综合题万能模板 ★

画图必标数据：三横线 727℃（共析）、1148℃（共晶）、1495℃（包晶）；纵轴标 1538℃（纯铁熔点）；横轴标 0.77%、2.11%、4.3%、6.69%；标出 L、γ、α、Fe₃C 各相区。

答题顺序（铁碳大题照此写）：

  1. 画相图轮廓并标出关键温度与成分；
  2. 按含碳量判断合金类型（对号入座）：
    - 工业纯铁 ≤0.0218%：F + Fe₃CⅢ
    - 亚共析钢 0.0218~0.77%：P + F
    - 共析钢 0.77%：P
    - 过共析钢 0.77~2.11%：P + Fe₃CⅡ
    - 亚共晶白口铸铁 2.11~4.3%：P + Fe₃CⅡ + Le′
    - 共晶白口铸铁 4.3%：Le′
    - 过共晶白口铸铁 4.3~6.69%：Fe₃CⅠ + Le′
  3. 需要时用杠杆定律算相/组织相对量（分母用两端点）；
  4. 简述平衡结晶过程。

例题（1.0%C 过共析钢）：

平衡结晶过程：L → L + γ → γ → γ + Fe₃CⅡ → P + Fe₃CⅡ（网状）。

九、附 B：渗碳铁棒组织分布（带图题）

题目：无限长纯铁棒 930℃ 渗碳（碳仅由顶端渗入），长期保温后缓冷至室温，标出 930℃ 与室温的组织分布。

答（从棒顶端向心部）：

  • 930℃：表面 Fe₃C + γ → 向内 γ（含碳量递减）→ 心部纯铁 F；
  • 室温：表面 Fe₃C → P + Fe₃C（网状） → P → P + F → F。

答题时务必画铁棒示意图，分两行（930℃ / 室温）从表面到心部标注。

十、易错提醒

  1. 杠杆定律只能用两相区（三相平衡线、单相区不能用）；
  2. 问"组织组成物"和"相组成物"要用不同端点——组织用共晶点分界，相用两端点分界；
  3. 单位先换算：mm → m，mJ/m² → J/m²，℃ 过冷度 = K 过冷度；
  4. 体积膨胀率按每原子体积算，别拿单胞体积直接比；
  5. 铁碳题先判断合金类型再写组织，别漏写"网状 Fe₃CⅡ"这类形态描述；
  6. 渗碳题把 Ws、W0、W、x、D 五个量先列全再代公式。
