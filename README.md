# 材料科学基础复习

材料科学基础（2026）复习资料，依据课程复习讲义与习题整理。

## 内容

- **闪卡.html**：互动闪卡（60 道选择题自测 + 名词解释 + 公式数字，带解析，进度保存在浏览器本地）
- **复习笔记**：8 章考点、公式、对比表、Fe-Fe3C / Pb-Sn 相图原图
- **复习计划**：14 天 / 5 天 / 1 天复习安排
- **anki_导入.csv**：98 张卡片，可导入 Anki 使用

## 使用

直接打开：**https://spagwet.github.io/materials-science-review/**

（本仓库已开启 GitHub Pages，`main` 分支根目录自动发布。）

资料仅用于个人学习复习。
